# WikiRabbit Vision

WikiRabbit is a small Windows desktop application created to demonstrate the **RailCoding development process**: planning with ChatGPT, building with Codex, testing real results, and refining the application through short, deliberate iterations.

The app runs quietly in the Windows system tray and presents one random Wikipedia topic each day. Opening the notification reveals a concise article preview, images, and two related links. Each choice expands into a visual exploration tree, allowing the user to follow connected topics through an ongoing Wikipedia rabbit hole.

## Project Goals

* Demonstrate how a non-traditional developer can plan and build a functional application with AI-assisted tools.
* Keep the architecture understandable, documented, and reproducible.
* Build features incrementally rather than attempting the entire application at once.
* Produce a convincing standalone Windows application suitable for use in the RailCoding video.

## Current Scope

The demonstration should prove the core experience:

1. Run as a Windows desktop and tray application.
2. Start automatically when the user signs in.
3. Select and display a daily Wikipedia article.
4. Show a readable article preview with relevant imagery.
5. Offer two linked articles for continued exploration.
6. Record those choices in a visual branching tree.

## Non-Goal

WikiRabbit is not currently intended to become a supported commercial product. Decisions should favor a clear, successful demonstration over production-scale infrastructure, broad platform support, or speculative features.
